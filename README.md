# JavaScript 🚀

This repository is a **complete JavaScript learning guide**, covering all concepts from **basic to advanced**.  
It is designed for **students, beginners, and intermediate developers** who want to build a **strong foundation** and move toward **advanced JavaScript concepts** step by step.

---

## 📌 Purpose of This Repository

- Learn JavaScript from **scratch**
- Understand **core concepts deeply**
- Practice concepts with **examples**
- Prepare for **web development**, **interviews**, and **real-world projects**

---

### 🔹 Basics
- Introduction to JavaScript
- Variables (`var`, `let`, `const`)
- Data Types
- Operators
- Type Conversion
- Input & Output
- Comments

### 🔹 Control Flow
- Conditional Statements (`if`, `else`, `switch`)
- Loops (`for`, `while`, `do-while`)
- Break & Continue

### 🔹 Functions
- Function Declaration & Expression
- Arrow Functions
- Parameters & Return Values
- Scope (Global & Local)
- Hoisting

### 🔹 Arrays & Strings
- Array Methods
- String Methods
- Iteration Techniques
- Destructuring

### 🔹 Objects
- Object Creation
- Properties & Methods
- `this` keyword
- Object Destructuring
- Shallow vs Deep Copy

### 🔹 Advanced JavaScript
- Closures
- Callbacks
- Promises
- Async / Await
- Event Loop
- Error Handling
- ES6+ Features

### 🔹 DOM & Browser
- DOM Manipulation
- Events
- Forms Handling
- Browser APIs
